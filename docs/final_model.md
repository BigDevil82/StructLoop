## 固定方案

| 项目 | 最终设置 |
|---|---|
| 案例与条件 | residential_001；`configs/residential_12_story.json`；12层×2.9m，原3/5/4层分区 |
| 本例参数 | C30，E=30GPa、G=12.5GPa；墙厚200/160/160mm；主梁250×500mm、次梁300×400mm；楼板厚120mm |
| 墙 | 每层每段输入墙1个MVLEM_3D；不作额外水平或竖向细分；纤维宽度目标0.2m且至少8条，配筋比例0.01，当前纤维材料为相同E的弹性材料 |
| 墙单元参数 | CoR=0.4（控制单元集中转动的位置）；剪切弹簧K=5GA/(6h)，单位N/m；面外采用MVLEM默认tMod=0.63（弯曲所用厚度的修正系数）、nu=0.25（面外泊松比） |
| 梁 | elasticBeamColumn，Euler梁（忽略梁的剪切变形）；所有主次梁的轴向、双向弯曲和扭转刚度完整保留；矩形截面采用Saint-Venant扭转常数 |
| 节点连接 | 原端点共节点；无附加梁高刚区、虚拟刚臂、梁端释放或人为钻转弹簧；Linear几何变换 |
| 边界与楼板 | 墙底六自由度固定；每个真实楼层仅UX/UY/RZ施加刚性楼板，主节点UZ/RX/RY固定 |
| 质量 | 按既有楼面荷载及构件自重计算，集中于原楼层主节点；中心及绕Z惯量沿用原端点协议，无网格附加质量 |
| 构件处理 | 分析墙段与共线直墙肢分别建账，保留交点；静力工况/每阶振型先按墙肢形心积分，再做组合；物理短墙保留原类别并经前置审查 |

本例共有162段墙和81根源梁，12层共1944个墙单元、972个梁单元。
建模入口：`adapters/fea.py` → `_vendor/shearwall_modeling/builders/mvlem_frame.py`。
计算代码校验值：`e49011b22005316c54e0bfcc858207ddaeb65a0935ddf3430631badae595ac62`，用于检查计算代码是否发生变化。
RC-GNN/CASINO权重及已修正的组合、校核、材料用量逻辑保持现状。

## 对应的已有结果

独立对照为ETABS 18.1 ShellThin墙与完整框架梁：相同几何、分区、底部固定、楼层刚性平面及规定质量。
墙板弯曲修正为0.63³；ETABS梁两向剪切面积修正系数1e6以对齐Euler梁，轴向/弯曲/扭转系数仍为1，
实际梁端偏移和刚域为0、无释放。屋顶X/Y分别施加1MN线弹性诊断力，材料容重为0；该诊断力不是设计荷载。
