独立对照为ETABS 18.1 ShellThin墙与完整框架梁：相同几何、分区、底部固定、楼层刚性平面及规定质量。

## 2026-10-30 校核修正与局部布局试验

按用户批准修正校核代码。MVLEM、Euler梁、节点连接和全部梁刚度保持上述方案；不重启软件比对。
当前生成布局为150段墙、77段梁。以下结果使用该布局及既有12层试算条件，不替代工程条件确认。

| 校核内容 | 本次修正 |
|---|---|
| 反应谱与周期 | 不再过滤异常特征值；周期必须落在输入谱内。由6阶开始逐次增加3阶，直至X、Y参与质量均达到90%；达到可提取上限仍不足则报错。本例实际9阶，原布局X=95.760%、Y=92.892% |
| 位移与扭转 | 每阶先作上下层位移差、端部平均，再组合；同时检查楼层位移比和层间位移比，避免先取峰值再平均丢失符号 |
| 层刚度 | K=层剪力/层间位移，单位N/m；同时保留相邻层0.7和上三层平均0.8门槛。汇总字段min_stiffness_ratio/0.7表示两者的最小余量；不足三层不套用三层平均条件 |
| 墙轴压 | 压力取正，拉力不冒充压力；保留控制组合 |
| 梁跨 | 按墙支座之间的共线构件识别物理跨；保留所有有限元分段和接入节点。两端有墙且至少一侧墙与梁夹角不超过30°时识别为连梁 |
| 受剪截面 | 梁、墙采用截面尺寸扣40mm纵筋合力点距离的有效高度；按对应组合的设计剪力/限值选控制项。普通箍筋连梁按跨高比2.5区分0.20/0.15系数，并计入0.85抗震调整系数；非地震梁按腹板高宽比采用0.25～0.20 |
| 设计剪力 | 沿用二级抗震的计算假定；底部两层墙剪力增大1.4。连梁以端弯矩绝对值之和及重力剪力上界计算1.2增大后的设计剪力，且不低于原组合剪力。CQC端部峰值不同时发生，该处理是保守上界，原始组合剪力另存 |
| 配筋 | 区分地震/非地震组合；HRB400采用360MPa设计强度；梁受弯调整系数0.75、墙0.85。墙逐组合按整个墙截面进行轴力—弯矩平衡与应变相容计算，不再混用墙端区高度和全墙有效高度；不计分布纵筋的有利抗弯作用。墙端区域重叠时不重复统计材料 |
| 数据完整性 | 缺失构件、缺失楼层、非有限数、空校核列表均不得当作通过；缺失周期比不再用T1/T3补造数值 |
