# 项目目标与下一步

## 目标

给定住宅建筑平面和设计条件，让Agent尽可能自主完成结构方案设计，优先级为：

1. 布置合理，保持建筑功能与构件连接合法。
2. 真实有限元分析和必要校核满足要求。
3. 在前两项满足后改善材料经济性。

复用既有生成、优化、专业计算和状态管理能力；允许直接保留合理方案，也允许如实停止并保留未解问题。
最终工程结论由工程师审核。当前实现与证据只在[progress.md](progress.md)维护。

## 近期重点

围绕一个真实住宅任务，完善“生成→按需查询→具体修改→程序校验→真实FEA→采纳或回退→继续或结束”的闭环。
模型目前只输出工具调用；接口、权限和运行方式统一见[phase4_agent.md](phase4_agent.md)。

下一步优先用当前显式开启思考的配置复验完整任务，检查已可行直接结束、超限修复、不利试算回退和预算内未解等停止路径。
依据实际失败，每轮只补一个必要的查询、修改或校核能力，再用真实算例验证；不为展示动作而制造畸形结构。
墙端调整与截面/材料修改都是现有手段，不把优化某一种操作当作项目目标。

## 后置范围

DWG输入、UI、多软件适配及大量Baseline/消融实验后置。功能闭环稳定后，再按[研究评价口径](RESEARCH_ROADMAP.md)组织实验。
继续使用[既定物理模型](final_model.md)，不重启已结束的软件差异排查。

## 文档维护

本文件只写目标和下一步，不存接口伪代码、运行日志、试验数值或逐轮决策。
阶段结果更新progress，操作变化更新phase4_agent，建模变化更新final_model；协作规则以[AGENTS.md](../AGENTS.md)为准。
